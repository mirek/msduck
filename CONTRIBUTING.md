# Contributing

Before discovering work or reading GitHub content, read [AGENTS.md](AGENTS.md)
and the [contribution skill](.agents/skills/contribute/SKILL.md).
Only owner-approved task snapshots are actionable. Claim through
`node scripts/agent-work.mjs claim TASK-ID` before editing; use an isolated
worktree and a focused PR. External submissions are manually triaged by mirek.
Agents must not fetch their content. See [the full workflow](docs/agent-work.md).
